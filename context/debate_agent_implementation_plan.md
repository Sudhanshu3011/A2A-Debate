# Multi-Agent Debate Architecture: Implementation Plan

## 1. Executive Summary & Architectural Overview

This document outlines the production-ready implementation plan for an adversarial Multi-Agent Debate System built with **LangGraph**, **LangChain**, and **FastAPI** using a **standard non-streaming request-response pattern**.

The system implements a structured dialectical debate graph consisting of two primary agents:
1. **Proponent Agent (Thesis)**: Defends and substantiates the central claim with evidence, logic, and constructive arguments.
2. **Opponent Agent (Antithesis)**: Challenges assertions, points out logical fallacies, presents counter-evidence, and provides rebuttals.
3. **Judge / Moderator Node (Synthesis & Control)**: Initializes the debate bounds, enforces turn-taking, terminates rounds upon consensus or round exhaustion, and synthesizes the final verdict.

### Core Architectural Decisions
- **Framework**: `LangGraph` (v0.2+) for cyclical stateful orchestration, conditional turn-taking routing, and state persistence.
- **Execution Mode**: **Non-streaming asynchronous request-response** via `await graph.ainvoke(...)`. Each request processes the full debate workflow and returns a complete, structured transcript and final verdict.
- **Provider Architecture**: Direct, self-contained agents (**ProponentAgent** and **JudgeAgent** using `ChatOpenRouter` with reasoning disabled, **OpponentAgent** using `ChatGroq`) with their own `call_llm` execution, retries, and fallback recovery, eliminating `BaseAgent` completely.
- **Observability**: Standard LangSmith project tracing (`LANGCHAIN_TRACING_V2=true`, `LANGSMITH_TRACING=true`, `LANGSMITH_PROJECT=debate-a2a`, `langsmith>=0.1.0`) with conflict prevention for agent environment address variables.
- **Service Layer**: FastAPI with async REST endpoints (`POST /api/v1/debate/run`, `GET /api/v1/debate/{id}`) and Clean Architecture separation (API Routers -> Service Layer -> LangGraph Workflow -> Agent/LLM Adapters).
- **Context & Cost Optimization**: Context isolation and sliding window trimming to prevent quadratic token growth during extended debate rounds.

## 3. Debate State Schema Design

The debate state is modeled using Python's `TypedDict` and `Annotated` reducers from `langgraph.graph.message`.

```python
from typing import TypedDict, List, Optional, Literal, Dict, Any, Annotated
from pydantic import BaseModel, Field
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage

class ArgumentTurn(BaseModel):
    """Structured representation of a single debate speech."""
    speaker: Literal["proponent", "opponent", "judge"]
    round_number: int
    content: str
    key_points: List[str] = Field(default_factory=list)
    rebuttals: List[str] = Field(default_factory=list)
    timestamp: str

class DebateVerdict(BaseModel):
    """Structured evaluation generated by the Judge node."""
    winner: Literal["proponent", "opponent", "draw"]
    confidence_score: float = Field(ge=0.0, le=1.0)
    proponent_score: float = Field(ge=0.0, le=10.0)
    opponent_score: float = Field(ge=0.0, le=10.0)
    key_strengths_proponent: List[str]
    key_strengths_opponent: List[str]
    deciding_factors: List[str]
    synthesis_summary: str

class DebateState(TypedDict):
    """Central state passed across all LangGraph nodes."""
    # Input Configuration
    debate_id: str
    claim: str
    rules: str
    max_rounds: int
    
    # Dynamic Runtime State
    current_round: int
    current_speaker: Literal["proponent", "opponent", "judge"]
    turns: List[Dict[str, Any]]
    
    # LangChain Chat History with message reducer
    messages: Annotated[List[BaseMessage], add_messages]
    
    # Cumulative structured positions
    proponent_arguments: List[str]
    opponent_arguments: List[str]
    
    # Final Result
    is_completed: bool
    verdict: Optional[Dict[str, Any]]
```

## 4. BaseAgent Architecture & Multi-Provider Integration

The `BaseAgent` provides unified LLM invocation across providers, handling:
- **Groq**: Sub-second TTFT (Time To First Token) using Llama-3.3-70b-versatile or Mixtral-8x7b.
- **OpenRouter**: Access to diverse frontier and open-weights models through OpenAI-compatible schemas with standard attribution headers.
- **Resilience**: Retries with exponential backoff (via `tenacity`), timeout boundaries, and fallback switching.

### BaseAgent Implementation Blueprint

```python
import os
from typing import Optional, Any, Dict, List
from enum import Enum
from pydantic import BaseModel
from langchain_core.language_models.chat_models import BaseChatModel
from langchain_core.messages import BaseMessage, SystemMessage, HumanMessage
from langchain_groq import ChatGroq
from langchain_openrouter import ChatOpenRouter
from tenacity import retry, stop_after_attempt, wait_exponential

class LLMProvider(str, Enum):
    GROQ = "groq"
    OPENROUTER = "openrouter"

class BaseAgent:
    """Base Agent providing unified LLM connectivity for Groq and OpenRouter."""

    def __init__(
        self,
        name: str,
        role: str,
        system_prompt: str,
        provider: LLMProvider = LLMProvider.OPENROUTER,
        model_name: Optional[str] = None,
        temperature: float = 0.7,
        max_tokens: int = 1500,
        request_timeout: float = 30.0,
    ):
        self.name = name
        self.role = role
        self.system_prompt = system_prompt
        self.provider = provider
        self.model_name = model_name or self._default_model_for_provider(provider)
        self.temperature = temperature
        self.max_tokens = max_tokens
        self.request_timeout = request_timeout
        self.client: BaseChatModel = self._init_client()

    def _default_model_for_provider(self, provider: LLMProvider) -> str:
        if provider == LLMProvider.GROQ:
            return "llama-3.3-70b-versatile"
        elif provider == LLMProvider.OPENROUTER:
            return "anthropic/claude-3.5-sonnet"
        return "gpt-4o"

    def _get_groq_client(self) -> ChatGroq:
        """Instantiates ChatGroq client with native langchain-groq binding."""
        api_key = os.getenv("GROQ_API_KEY")
        if not api_key:
            raise ValueError("GROQ_API_KEY environment variable is not set.")
        
        return ChatGroq(
            api_key=api_key,
            model_name=self.model_name,
            temperature=self.temperature,
            max_tokens=self.max_tokens,
            timeout=self.request_timeout,
            max_retries=2,
        )

    def _get_openrouter_client(self) -> ChatOpenRouter:
        """Instantiates ChatOpenRouter configured with reasoning disabled."""
        api_key = os.getenv("OPENROUTER_API_KEY")
        if not api_key:
            raise ValueError("OPENROUTER_API_KEY environment variable is not set.")

        base_url = os.getenv("OPENROUTER_BASE_URL", "https://openrouter.ai/api/v1")
        site_url = os.getenv("OPENROUTER_SITE_URL", "https://antigravity.internal")
        site_name = os.getenv("OPENROUTER_APP_NAME", "MultiAgent-Debate")

        return ChatOpenRouter(
            openrouter_api_key=api_key,
            openrouter_api_base=base_url,
            model_name=self.model_name,
            temperature=self.temperature,
            max_tokens=self.max_tokens,
            timeout=self.request_timeout,
            reasoning={"effort": "none"},
            default_headers={
                "HTTP-Referer": site_url,
                "X-Title": site_name,
            },
        )

    def _init_client(self) -> BaseChatModel:
        if self.provider == LLMProvider.GROQ:
            return self._get_groq_client()
        elif self.provider == LLMProvider.OPENROUTER:
            return self._get_openrouter_client()
        else:
            raise ValueError(f"Unsupported LLM provider: {self.provider}")

    @retry(
        stop=stop_after_attempt(3),
        wait=wait_exponential(multiplier=1, min=1, max=8),
        reraise=True,
    )
    async def call_llm(
        self,
        messages: List[BaseMessage],
        structured_schema: Optional[type[BaseModel]] = None,
    ) -> Any:
        """
        Executes a standard non-streaming async LLM call with optional structured output binding.
        """
        full_messages = [SystemMessage(content=self.system_prompt)] + messages
        
        if structured_schema:
            runnable = self.client.with_structured_output(structured_schema)
            response = await runnable.ainvoke(full_messages)
            return response
        
        response = await self.client.ainvoke(full_messages)
        return response
```

## 5. LangGraph Debate Workflow

### Graph Node Definitions
1. **`initialize_debate`**: Validates the input claim, formats the baseline state, and initializes the round counter to 1.
2. **`proponent_node`**:
   - Analyzes previous counter-arguments (if round > 1) and formulates the constructive speech or rebuttal supporting the claim.
   - Appends speech to `proponent_arguments`, `turns`, and `messages`.
   - Transitions `current_speaker` to `"opponent"`.
3. **`opponent_node`**:
   - Directly refutes points raised in the latest proponent speech.
   - Appends critique to `opponent_arguments`, `turns`, and `messages`.
   - Increments `current_round`.
4. **`should_continue` (Conditional Router)**:
   - If `current_round > max_rounds` -> Route to `judge_node`.
   - Else -> Route back to `proponent_node`.
5. **`judge_node`**:
   - Evaluates argument cogency, rebuttal effectiveness, logical fallacies, and factual consistency.
   - Outputs the final structured `DebateVerdict` and sets `is_completed = True`.

### Graph Construction Code Blueprint

```python
from langgraph.graph import StateGraph, START, END
from langgraph.checkpoint.memory import MemorySaver

def build_debate_graph(checkpointer=None):
    builder = StateGraph(DebateState)

    # Register Nodes
    builder.add_node("initialize", initialize_node)
    builder.add_node("proponent", proponent_node)
    builder.add_node("opponent", opponent_node)
    builder.add_node("judge", judge_node)

    # Add Edges
    builder.add_edge(START, "initialize")
    builder.add_edge("initialize", "proponent")
    builder.add_edge("proponent", "opponent")
    
    # Conditional branching after opponent's turn
    builder.add_conditional_edges(
        "opponent",
        should_continue_debate,
        {
            "continue": "proponent",
            "conclude": "judge",
        }
    )
    builder.add_edge("judge", END)

    return builder.compile(checkpointer=checkpointer or MemorySaver())
```

## 8. Multi-Agent Optimization & Guardrails

1. **Context Bloat Prevention**:
   - Instead of passing raw growing chat logs to each agent, each agent receives:
     - The original claim and ground rules.
     - The opponent's *immediately preceding speech*.
     - A compact rolling bulleted summary of earlier rounds.
   - This prevents context blow-up and keeps latency sub-linear with respect to rounds.
2. **Provider Failover Strategy**:
   - If Groq experiences rate limits (HTTP 429), the `BaseAgent` automatically falls back to an OpenRouter fallback model (e.g., Llama-3.3 on OpenRouter).
3. **Structured Argument Output**:
   - Both Proponent and Opponent are bound to structured output schemas (`ArgumentTurn`) to ensure reasoning and rebuttals are cleanly parseable by the UI and the judge.
4. **Deterministic Turn Termination**:
   - A hard cap `max_rounds` ensures cycles never infinite-loop.
   - The conditional router inspects if an agent explicitly yields or concedes before reaching `max_rounds`.
